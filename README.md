# pax-corporations
Pax Universe · Pax Corporations — Глобальная модификация, которая добавляет разнообразные всемирные корпорации, данный мод прямо влияет на экономику и мировую арену.

| Папка | Что это |
|---|---|
| `pax_corporations/` | сам мод — папку целиком положить в `mods/` игры |

Текущая версия: **5.9.1**. История — `pax_corporations/CHANGELOG.md`.

Проверка мода из папки игры: `PaxUniverse.exe --headless -- --check-mods pax_corporations`.
